# 🌙 نور — Noor Islamic Platform (APK Ready)

## 🔗 الرابط الحقيقي: https://al-islam-nour.netlify.app/

## 🚀 بناء الـ APK

### الطريقة 1: Android Studio (الأسهل)

1. حمّل Android Studio من [developer.android.com/studio](https://developer.android.com/studio)
2. افتح المشروع: File → Open → اختار `noor-apk-ready`
3. استنى Gradle sync
4. اضغط: Build → Build Bundle(s) / APK(s) → Build APK(s)
5. هتحصل على `app-debug.apk`

### الطريقة 2: Command Line

```bash
export ANDROID_HOME=$HOME/Android/Sdk
./gradlew assembleDebug
```

## 📱 التثبيت

1. بعت `app-debug.apk` للناس
2. يفعلوا "Unknown sources" في الإعدادات
3. يثبتوه زي أي تطبيق Android
